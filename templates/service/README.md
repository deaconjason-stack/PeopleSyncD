# Service Template

Every service contains:

- `README.md`
- `docs/architecture.md`
- `docs/domain.md`
- `docs/security.md`
- `docs/operations.md`
- `api/openapi.yaml`
- `events/asyncapi.yaml`
- `database/schema.md`
- `src/`
- `tests/`
- `Dockerfile`

Each artifact links requirements, specifications, ADRs, contracts, implementation, tests, and certification evidence.
