# Domonique 2.0 AI Permissions

- `ai.conversation.start`
- `ai.conversation.use`
- `ai.sources.read`
- `ai.tool.invoke`
- `ai.action.approve`
- `ai.action.cancel`
- `ai.memory.read.own`
- `ai.memory.manage.own`
- `ai.memory.manage.tenant`
- `ai.audit.read`
- `ai.admin.configure`

Default is deny. Assistant mode, model output, prompt text, or prior access cannot grant permission.
