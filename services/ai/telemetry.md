# Domonique 2.0 AI Telemetry

Metrics include request latency, model latency, retrieval latency, grounding coverage, citation failures, refusals, prompt-injection detections, tool calls, approval latency, stale actions, token and cost budgets, memory operations, provider errors, and fallback use.

Logs and traces exclude raw prompts, secrets, highly confidential content, and unrestricted source passages by default.
