# Domonique 2.0 AI Audit

Record conversation start and close, assistant mode, retrieval purpose, source identifiers, policy decisions, refusals, tool selection, tool arguments in minimized form, approval request, approver, execution result, memory create/read/update/delete, safety event, model route, and kill-switch use.

Audit evidence must not become an unrestricted copy of prompts, secrets, or sensitive records.
