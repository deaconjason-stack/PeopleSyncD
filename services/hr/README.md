# PeopleSyncD HR Service

The HR bounded context is the first major PeopleSyncD application domain. It coordinates Person, Worker, Employment, Onboarding, Credentials and Training, HR Cases, workforce documents, dashboards, and Board Portal integration while reusing shared platform services.

## Current specification set

- `PSD-PEP-300` HR Domain
- `PSD-PEP-301` Person Service
- `PSD-PEP-302` Employment and Assignment Service
- `PSD-PEP-303` Onboarding Service
- `PSD-PEP-304` Credentials and Training
- `PSD-PEP-305` HR Cases and Concerns
- `PSD-PEP-306` HR User Experience and Dashboards
