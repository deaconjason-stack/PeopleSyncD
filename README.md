# PeopleSyncD

**PeopleSyncD HR with Domonique 2.0** is a governance-first, AI-assisted workforce operating system from MediSyncD Technologies.

PeopleSyncD is being designed as an enterprise platform with requirements traceability, architecture decision records, versioned API contracts, secure service boundaries, immutable audit evidence, and release certification.

## Repository map

- `docs/pep/` — PeopleSyncD Enhancement Proposals and governing standards
- `docs/adr/` — architecture decision records
- `docs/rfc/` — requests for comment
- `docs/api/` — OpenAPI service contracts
- `docs/asyncapi/` — asynchronous event contracts
- `docs/traceability/` — requirement-to-release evidence
- `services/` — service specifications and implementation roots
- `database/` — schemas, constraints, indexes, views, and migrations
- `release/` — release notes, certification, SBOM, reports, checksums, and signatures

## Status

This repository is in governance and architecture foundation status. Metrics such as requirement counts, test counts, coverage, certification, and signed-build status must be generated by CI or release evidence and must never be stated as complete without verifiable artifacts.

## Security

Never commit credentials, tokens, private keys, employee records, protected personal information, or production secrets. Follow `SECURITY.md` for vulnerability reporting.
