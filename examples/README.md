# Examples

This directory contains safe, reviewable examples for developers, administrators, implementers, partners, and customers.

## Permitted content

- Synthetic API requests and responses
- Sanitized event payloads
- Fictional tenant, organization, person, worker, and workflow records
- Example configuration with placeholders
- Local development scenarios
- SDK and integration walkthroughs
- Demonstration policies and approval flows
- Non-production deployment examples

## Prohibited content

- Real customer, worker, applicant, student, patient, resident, or employee information
- Real credentials, tokens, keys, secrets, connection strings, or recovery codes
- Real health, tax, payroll, background-check, accommodation, disciplinary, or legal data
- Customer-specific network, infrastructure, or security details
- Examples that imply unsupported certification or production readiness

## Governance

Every example must identify its intended audience, associated contract or specification, supported version, safety limitations, and validation method. Examples are subordinate to approved contracts and must be updated or retired when those contracts change.

Synthetic examples should exercise tenant context, permissions, privacy-safe audit evidence, validation failures, idempotency, and rollback behavior where applicable.
