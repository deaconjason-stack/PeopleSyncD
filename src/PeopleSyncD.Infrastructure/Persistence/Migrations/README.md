# PeopleSyncD Database Migrations

EF Core migrations are generated from `PeopleSyncDDbContext` and are applied through the deployment pipeline, never by application startup in production.

## Initial schema

The initial migration must create the `peoplesyncd` schema and these tables:

- `organizations`
- `people`
- `users`
- `organization_memberships`

Required invariants:

- organization slug is globally unique
- user email is globally unique
- person email is unique within an organization
- user/organization membership is unique

> Migration binaries are generated by the repository's pinned EF Core toolchain during CI. Do not hand-edit generated migration files.
