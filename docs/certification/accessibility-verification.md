# Accessibility Certification Plan

Certification evidence covers core Founder, HR, Manager, Employee, Board, Document, Onboarding, Approval, and Domonique 2.0 workflows.

Required evidence includes keyboard completion, focus sequence, screen-reader output, headings and landmarks, names and descriptions, contrast, zoom and reflow, reduced motion, captions and transcripts, form errors, status announcements, touch targets, localization, and documented exceptions.

Current status: plan defined; no released UI has been certified.
