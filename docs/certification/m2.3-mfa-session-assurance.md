## Security qualification

Recovery codes and MFA challenge bearer secrets are stored only as SHA-256 hashes. TOTP shared secrets are intentionally recoverable because RFC 6238 verification requires the shared secret; production certification therefore requires protected database storage, backup protection, and production key custody for authenticator secrets.

M2.3 provides a fresh `step_up` challenge mechanism, but does not yet bind individual high-impact business operations to a maximum authentication age.

## Release boundary

M2.3 is verified as a buildable and tested engineering milestone. It is **not** a production-certified customer release.
