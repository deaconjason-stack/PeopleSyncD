# Genesis Foundation Certification Definition

## Scope

The Genesis 0.1.0 package certifies the engineering repository structure and evidence automation only after all declared gates pass. It does not certify executable production software, customer deployment, healthcare compliance, government authorization, AI autonomy, or Windows distribution.

## Current decision

Not certified. The repository package includes draft evidence structure, validation automation, and target controls. Product implementation, automated product tests, signed software artifacts, penetration testing, accessibility verification, performance results, backup restoration, and disaster-recovery exercises remain incomplete.
