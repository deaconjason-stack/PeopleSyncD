- Fido2 4.0.1 WebAuthn verification on the existing .NET 9 runtime;
- configuration-bound relying-party ID and accepted origins;
- passkey registration options requiring WebAuthn user verification and resident credentials;

- email-first passwordless passkey authentication;

- preservation of the original authentication instant and method across refresh-token rotation;
- a five-minute maximum-authentication-age policy for the initial classified privileged actions;
- privileged reauthentication on passkey enrollment/revocation and organization invitation/membership mutation;
- browser WebAuthn challenge conversion and attestation/assertion serialization; and
- OpenAPI 0.2.4, security-model, requirements, traceability, and release documentation for the M2.4 scope.
