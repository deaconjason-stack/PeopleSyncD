# PEP-0010: Documentation Standard

- Status: Accepted

All governed documents must state purpose, scope, status, owner, decision, security and privacy effects, compatibility, testing, migration, and traceability. Markdown is the canonical narrative format; OpenAPI, AsyncAPI, SQL, JSON Schema, Mermaid, SBOM, checksums, and signatures are machine-verifiable evidence. Documents must not claim completion, certification, coverage, signing, or compliance without generated artifacts.
