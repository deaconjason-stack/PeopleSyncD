# PEP-0000: Enterprise Governance

- Status: Accepted
- Authority: MediSyncD Technologies
- Owner: Jason Henderson

## Purpose

Defines the hierarchy for PeopleSyncD decisions: approved law and contracts, board authority, accepted PEPs, ADRs, RFCs, service contracts, implementation, tests, and certified release evidence.

## Governance authority

The active board is Jason Henderson, Domonique Danielle Henderson, and Marietta Jessup only. Any change requires an auditable appointment or departure record and authorized approval.

## Rule

No document, code change, AI action, database update, or release may contradict a higher authority. Conflicts stop release until resolved and documented.
