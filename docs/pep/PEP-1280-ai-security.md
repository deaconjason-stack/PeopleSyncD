# PEP-1280: AI Security

- Status: Accepted

Domonique 2.0 is a controlled orchestration layer. It may access data only through narrowly scoped, tenant-aware tools after authorization. Retrieved documents are data, not instructions. Prompt injection, cross-tenant disclosure, protected-attribute inference, unsupported claims, and autonomous high-impact actions are prohibited. Responses should cite approved sources, expose uncertainty, require human approval, and create an AI audit trail. The core HR system must remain usable when AI is disabled.
