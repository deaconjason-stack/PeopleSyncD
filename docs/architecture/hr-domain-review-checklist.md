# HR Domain Architecture Review Checklist

- [ ] Service ownership is explicit.
- [ ] Tenant isolation is enforced at every layer.
- [ ] Permission and relationship scopes are documented.
- [ ] Highly confidential data is separated.
- [ ] API and event contracts are versioned.
- [ ] Database changes include migration and rollback guidance.
- [ ] Audit evidence covers successful and denied actions.
- [ ] Notifications avoid restricted data leakage.
- [ ] UI specifications include accessibility and privacy tests.
- [ ] Domonique 2.0 remains permission-aware and human-approved.
- [ ] Board authority remains owned by the Board service.
- [ ] Certification claims are evidence-based.
