# Support Diagnostics

Support collection is allowlist-based. Approved bundles may include release manifest, checksums, sanitized configuration metadata, service health, non-sensitive error codes, dependency status, resource summaries, and correlation identifiers.

Bundles must exclude secrets, tokens, cookies, private keys, raw prompts, unrestricted workforce records, document content, HR case narratives, compensation, medical or accommodation information, and identity documents.

Customers review a bundle before sharing. Support access is time-bounded, revocable, and audited.
