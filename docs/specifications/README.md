# PeopleSyncD Specifications

Approved specifications define product, platform, service, application, UI, AI, security, data, and operational behavior before implementation.

## Current sequence

- `PSD-PEP-100` through `PSD-PEP-150`: product and foundational architecture
- `PSD-PEP-210` through `PSD-PEP-280`: shared core platform services
- `PSD-PEP-300` through `PSD-PEP-306`: PeopleSyncD HR domain and experience
- `PSD-PEP-3010`: Worker service foundation retained for compatibility during consolidation

The registry is `docs/specifications/registry.yaml`.
