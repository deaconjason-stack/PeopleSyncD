# HR User Experience and Dashboard Specification

## Surfaces

- Founder Dashboard
- HR Administration Workspace
- Manager Workspace
- Employee Self-Service
- People Directory
- Person and Worker profiles
- Onboarding Center
- Credential and Training Center
- HR Case Workspace
- Board Portal integration

## Required UI specification fields

Purpose, navigation, permissions, components, empty states, keyboard behavior, screen-reader labels, contrast, zoom, localization, performance budget, analytics, errors, and automated tests.

## Founder Dashboard

Founder views may summarize active workers, current board, onboarding risks, credentials, approvals, documents, security events, and recent activity. Restricted details remain hidden unless separately authorized.
