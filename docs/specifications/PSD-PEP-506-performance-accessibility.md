# Performance and Accessibility Verification

## Performance

Approved budgets define latency, throughput, concurrency, startup time, package size, resource use, queue age, error rate, and recovery behavior by workflow and deployment model. Results identify environment, dataset, workload, duration, percentile, and limitations.

## Accessibility

Verification covers keyboard operation, focus, screen readers, semantic structure, contrast, zoom, reduced motion, captions, form errors, touch targets, localization, and voice alternatives.

## Certification rule

A target, checklist, automated scan, or laboratory result alone does not establish production performance or accessibility certification. Evidence must cover the released artifact and declared environment.
