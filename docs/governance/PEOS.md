# PeopleSyncD Enterprise Operating System

PeopleSyncD HR is the first application. The reusable platform underneath it is the long-term product.

PEOS consists of shared platform services, business applications, SDK, CLI, documentation, marketplace, deployment packages, and certification evidence coordinated through versioned manifests.
