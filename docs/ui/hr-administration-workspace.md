# HR Administration Workspace UI Specification

## Purpose

Allow authorized HR users to manage people, employment, onboarding, credentials, training, documents, approvals, and restricted cases.

## Navigation

People, Employment, Onboarding, Credentials, Training, Documents, Cases, Approvals, Reports, and Audit.

## Security

Restricted case content, highly confidential documents, compensation, identity documents, accommodation information, and screening information require separate permissions and may require fresh authentication.

## Accessibility

All tables support keyboard navigation, filters have labels, validation errors identify affected fields, and status changes include text descriptions.
