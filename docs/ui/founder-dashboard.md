# Founder Dashboard UI Specification

## Purpose

Provide Jason Henderson and other explicitly authorized executive users with a concise, source-linked view of workforce priorities.

## Components

Active workers, active board, pending approvals, onboarding risks, credential alerts, document alerts, security events, recent activity, and Domonique 2.0 Founder Brief.

## Governance rule

The active board display must contain only Jason Henderson, Domonique Danielle Henderson, and Marietta Jessup unless an approved Board service change becomes effective.

## Accessibility and performance

Cards are keyboard reachable, status does not rely on color, headings are hierarchical, loading is independent per card, and failure of one card does not block the page.

## Tests

Permission filtering, board accuracy, empty states, loading failures, keyboard operation, screen readers, zoom, and restricted-count leakage.
