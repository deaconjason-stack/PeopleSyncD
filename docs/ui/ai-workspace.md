# Domonique 2.0 AI Workspace UI Specification

## Purpose

Provide a transparent workspace for conversation, sources, prepared actions, approvals, memory controls, and safety state.

## Components

Conversation stream, assistant-mode selector, source panel, tool preview, approval drawer, memory manager, voice control, model-status notice, and audit link.

## Required behavior

Users can distinguish sourced facts, drafts, calculations, inferences, refusals, and executed actions. Tool arguments and consequences are previewed before approval. Restricted sources do not leak through titles, counts, URLs, or snippets.

## Accessibility

Keyboard-complete interaction, screen-reader announcements, visible focus, status text independent of color, transcript correction, captions for voice output, and reduced-motion support.
