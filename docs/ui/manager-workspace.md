# Manager Workspace UI Specification

## Purpose

Provide managers with authorized direct-report summaries, onboarding tasks, training status, approvals, and team actions without unrestricted personnel-file access.

## Permission boundary

Manager status alone does not grant access to HR cases, identity documents, compensation, board records, accommodation information, or unrelated workers.

## Tests

Direct-report scope, relationship changes, denied deep links, restricted summaries, delegation expiration, keyboard access, and notification privacy.
