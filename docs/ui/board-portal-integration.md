# Board Portal Integration Specification

## Purpose

Coordinate HR-facing onboarding and directory references with the Board service without allowing HR to create or alter governance authority.

## Authoritative board

The current active MediSyncD Technologies board consists only of Jason Henderson, Domonique Danielle Henderson, and Marietta Jessup.

## Rules

- Board appointments are created, ended, and queried through the Board service.
- HR may coordinate approved onboarding tasks and documents.
- Board membership alone does not grant unrelated personnel-file access.
- Former appointments remain historical and do not appear in active-board results.
