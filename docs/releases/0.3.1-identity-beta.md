# PeopleSyncD Genesis 0.3.1 Identity Beta

Phase 7B1 adds persistent membership authority, server-side revocable sessions, logout invalidation, pending MFA enrollment records, identity security events, and an external-identity schema foundation.

The release is an unsigned engineering beta and is not production certified. OIDC or SAML login, completed MFA verification and recovery, independent security testing, and protected signing are not included.
