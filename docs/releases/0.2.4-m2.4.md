# PeopleSyncD 0.2.4 — M2.4 Engineering Milestone

M2.4 adds a WebAuthn/passkey and privileged-reauthentication foundation to the verified M2.3 identity platform.

Implemented scope includes configuration-bound relying-party/origin validation, required-user-verification passkey registration, resident credentials, email-first passwordless passkey login, passkey step-up, credential inventory and revocation, server-side public credential persistence, single-use ceremony state, phishing-resistant session assurance, authentication-time preservation across refresh rotation, a five-minute privileged-operation freshness policy, browser WebAuthn ceremony support, and PostgreSQL persistence.

This is an engineering milestone, not a production-certified customer release. CI does not provide a physical platform authenticator or roaming security key, so live-authenticator acceptance remains a separate operational verification item. Production RP/origin settings, browser refresh-token custody, independent security review, signed packaging, and deployment approval also remain required.
