# PeopleSyncD 0.2.2 — M2.2 Engineering Milestone

M2.2 adds user administration and session-security foundations to the .NET/Next.js platform.

Highlights include organization invitations, membership role/status administration, email verification, rotating refresh-token families with reuse detection, live membership validation, security audit evidence, a user-administration workspace, and a fail-closed MFA-ready login boundary.

This is an engineering milestone, not a production-certified customer release. Production email delivery, complete MFA, hardened browser session custody, production key custody, operational review, signed packaging, and deployment approval remain required.
