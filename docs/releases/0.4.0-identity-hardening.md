# PeopleSyncD Genesis 0.4.0 — Identity Hardening

## Status

Unsigned engineering build for internal verification. Not production certified.

## Implemented

- RFC 6238-compatible TOTP enrollment and verification.
- AES-256-GCM protection of TOTP secrets at rest.
- Dedicated production MFA encryption-key configuration.
- Keyed recovery-code hashes with one-time plaintext display.
- Atomic session-family rotation and immediate replacement-token enforcement.
- Membership status and permission administration.
- Immediate session revocation when membership is suspended or ended.
- Expanded security events, schema assertions, unit tests, PostgreSQL integration tests, SBOM, checksums, and Windows packaging.

## Preserved safeguards

- Explicit tenant context.
- Current membership and permission authority on every protected request.
- Forced PostgreSQL row-level security.
- Append-only audit and security evidence.
- Authoritative board membership: Jason Henderson, Domonique Danielle Henderson, and Marietta Jessup only.
- Domonique 2.0 remains restricted to registered, permission-aware tools.

## Not implemented

- WebAuthn registration and authentication ceremonies.
- Recovery-code consumption or account recovery.
- Production OIDC, SAML, OAuth2, or SCIM.
- Last-Founder and separation-of-duties invariants.
- Separate deployed-runtime database login credentials.
- Code signing, independent penetration testing, accessibility certification, resilience certification, or customer-production approval.

## Release decision

This build may be used only for controlled engineering and security verification. It may not be represented as a complete production identity system or a certified commercial release.
