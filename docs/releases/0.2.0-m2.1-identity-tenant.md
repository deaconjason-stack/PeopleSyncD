# PeopleSyncD 0.2.0 M2.1 Engineering Release

## Classification

Engineering milestone. Not customer-certified.

## Included

- Identity and organization-membership domain model.
- Owner and tenant registration use case.
- Password login and tenant selection use cases.
- JWT validation and permission policies.
- Tenant-bound organization API.
- Identity and organization-selection web workspace.
- PostgreSQL additive migration.
- Deterministic npm lockfile and `npm ci` builds.
- Expanded automated tests and API contract.

## Excluded

- Production signing-key provisioning.
- Email verification delivery.
- Refresh tokens and MFA.
- Federation and SCIM.
- Production deployment authorization.
