# Genesis 0.1.0 Known Issues

- Product services and clients are not implemented.
- Docker provides dependencies only, not PeopleSyncD application containers.
- Kubernetes application images are template references and are not published or signed.
- SBOM, checksums, and signatures are not generated in this committed draft.
- Product security, accessibility, performance, backup restoration, disaster recovery, and penetration-test evidence are not complete.
- Windows installer and Authenticode signing are not available.
